# Grammar Snake 🐍

英语教育贪吃蛇游戏 — 将经典贪吃蛇玩法与英语单词学习相结合。

## 功能特性

- **单词拼写**：蛇吃到字母后需正确拼写单词得分
- **题库系统**：内置英语题库，支持多难度等级
- **连击系统**：连续答对获得连击加成
- **计时挑战**：限时模式，答对加时、答错扣时
- **称号系统**：根据表现解锁不同称号

## 技术栈

- Python 3.11
- Pygame

## 运行方式

```bash
pip install pygame
python main.py
```

## 项目结构

```
├── main.py              # 入口
├── config.py            # 全局配置
├── game/                # 游戏核心（蛇、字母、导演）
├── education/           # 教育模块（题库、题目）
├── systems/             # 系统模块（事件总线、计分、计时）
├── ui/                  # UI模块（渲染、HUD、特效）
├── data/                # 数据文件（题库JSON）
└── assets/              # 资源文件
```
